Flexbox playground

Change a property and watch the items move. It follows the CSS-Tricks flexbox guide; the Flexbox wiki page explains every property.

Container

flex turns the box into a flex container. inline-flex does the same, but the box sits inline, like a word in a sentence.

Sets the main axis, the direction items are placed in. The cross axis is always the other one.

nowrap squeezes everything onto one line. wrap lets items move to a new line when they run out of room.

Shares the free space along the main axis. Nothing moves when an item grows and leaves no free space.

Lines items up on the cross axis, inside their line. stretch makes them fill the line, unless they have a fixed size.

Spreads the lines on the cross axis. It only does something when items wrap onto several lines and the container is taller than they are.

gap is the space between items. It never adds space at the outer edges.

Width and height are not flexbox properties. Change them to see how the items react to more or less space.

Item

More content makes an item want more room, which changes how grow and shrink share the space.

grow: how much of the free space this item takes, compared with the others (0 takes none). shrink: how much it gives up when space is short (0 never shrinks).

The starting size before growing or shrinking. auto uses the width (or the content size when there is no width).

order changes only the visual order: screen readers and the Tab key still follow the HTML. align-self overrides align-items for this one item.

An auto margin takes all the free space on that side and pushes the item away. margin-left: auto sends a navbar's links to the right.

A fixed size, for example 120px or 30%. Leave empty to size by the content.

Presets

Select an item to edit it. The number on each item is its place in the HTML, which order does not change.
