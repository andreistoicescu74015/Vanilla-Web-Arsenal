Grid playground

Define tracks, then place items on the numbered lines. It follows the CSS-Tricks grid guide; the Grid wiki page explains every property.

Container

One size per column. fr is a share of the free space, so 1fr 2fr makes the second column twice as wide.

Explicit rows. Leave it empty and the browser adds rows as items need them.

The size of the rows the browser adds on its own (the implicit grid).

Names regions of the grid. Each quoted line is one row with one name per column; an item joins a region with grid-area. A dot leaves a cell empty.

Space between tracks, never at the outer edges.

Position every item inside its cell: justify-items horizontally, align-items vertically. normal stretches items to fill the cell.

Move the whole grid inside the container. They only matter when the tracks are smaller than the container, for example with fixed px columns.

grid-auto-flow decides where items without a position go. dense fills earlier holes, which changes the visual order, so avoid it when the order matters. Height is not a grid property; it gives the rows room to show 1fr and align-content.

Item

Which column lines the item runs between. 1 / 3 goes from line 1 to line 3, span 2 covers two tracks, 1 / -1 goes from the first line to the last.

The same idea for rows. The line numbers drawn on the preview help.

Puts the item in a named region from grid-template-areas, for example header.

Override justify-items and align-items for this one item.

Presets

Select an item to edit it. The small numbers along the edges are grid lines: use them in grid-column and grid-row. The number on each item is its place in the HTML.
