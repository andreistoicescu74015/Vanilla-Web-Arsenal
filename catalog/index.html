Setup

Link one stylesheet and the scripts you need. The scripts are plain files, so the page also works when you double-click it and it opens from disk.

<link rel="stylesheet" href="arsenal/css/arsenal.css">
<link rel="stylesheet" href="css/style.css">  <!-- your own CSS, always wins -->

<script defer src="arsenal/js/dom.js"></script>
<script defer src="arsenal/js/utils.js"></script>
<script defer src="arsenal/js/icons.js"></script>
<script defer src="arsenal/js/ui.js"></script>
<script defer src="js/main.js"></script>

One rule to remember: classes are looks, data-* attributes are behavior. class="tabs" styles a set of tabs; data-tabs makes them switch.

Themes and presets

One attribute on <html> changes the brand colors, the corner radii and the heading font together. Pick one here and the whole catalog follows; the choice is remembered on this page.

<!-- In every page of your project -->
<html lang="en" data-preset="forest">

The default theme needs no attribute. Headings use Space Grotesk, which is embedded in arsenal/css/fonts.css and works offline; the presets switch to system fonts (serif for Editorial, rounded where available for Forest and Candy). For your own colors, use the theme builder: it checks the contrast and writes the code.

Buttons

Use <button> for actions and <a class="btn"> for navigation. Every button is at least 44px tall, a comfortable touch target. Icon-only buttons need an aria-label. Give each screen one primary button; the gradient button is for the single most important action on a page.

Cards

Cards in the same row stretch to the same height, and .card-footer lines up at the bottom. .card-link makes the whole card clickable through one real link, which keeps it accessible; only cards that are links should lift on hover. .card-featured marks the one card in a row that should stand out.

Forms

Labels sit above fields and every field has one. Mark the optional fields, not the required ones. With data-validate on the form, errors appear under each field after a submit attempt, written from the field's label ("Full name is required."), and update while the user fixes them. A checkbox without a .field wrapper gets its message right after its label. Try submitting the empty form.

Tabs

Tabs show one panel at a time. class="tabs" is the look, data-tabs the behavior: click a tab, or focus one and use the arrow keys, Home and End. Add .pills for a pill-style switch. When the options filter a single view instead of switching panels, use the segmented control above.

Accordion

Native <details>, so it works without JavaScript. Items that share a name close each other, and the browser search (Ctrl + F) finds text inside closed items.

Can we use this at the hackathon?

Yes. It is plain HTML, CSS and JavaScript that you wrote and prepared before the event.

Does it work offline?

Yes. The heading font is embedded, body text uses system fonts, and icons are inline SVG, so nothing loads from the internet.

Do we need a build step?

No. Open the HTML file in a browser and it runs.

Dropdown and tooltip

The dropdown is a <details data-dropdown> that closes on outside clicks and Esc. The tooltip is pure CSS and Esc hides it; repeat its text in aria-label, because screen readers skip it.

Toast

Short feedback after an action. Screen readers announce it through an aria-live region. The countdown pauses while the pointer or focus is on the toast, and errors stay until someone dismisses them. An action adds a button such as "Undo", which beats asking "Are you sure?" for actions that are easy to reverse.

Table

Wrap tables in .table-wrap so they scroll sideways on phones instead of breaking the layout. Numbers align right in .num cells. With .table-stacked and a data-label on each cell, every row becomes a small card on phones instead: narrow the window to see it.

File upload

.dropzone is a large label around a file input: click it, reach it with Tab and press Space, or drop a file on it. The arsenal styles it; showing a preview takes a few lines of your own script (see catalog/catalog.js).

Loading states

Show a skeleton where content will appear, a spinner for short waits, and a progress bar when you know how far along the task is. Spinners keep turning, slower, for people who ask for reduced motion, so the page never looks frozen.

Charts

arsenal/js/charts.js draws bar, line and donut charts as SVG, in the theme colors. Each chart also writes its numbers into a table that only screen readers see (the donut's legend is that list), and redraws itself when its container changes width.

<script defer src="arsenal/js/charts.js"></script>

VWA.chart.bar("#demo-bar-chart", {
  labels: ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"],
  values: [12, 18, 9, 22, 17, 26, 24],
  label: "Tasks completed per day",
  highlight: 5,
});
VWA.chart.line("#demo-line-chart", {
  labels: ["Week 1", "Week 2", "Week 3", "Week 4", "Week 5"],
  series: [{ name: "Visits", values: [120, 180, 150, 240, 300] }, { name: "Sign-ups", values: [20, 35, 30, 60, 90] }],
  label: "Visits and sign-ups per week",
});
VWA.chart.donut("#demo-donut-chart", {
  segments: [{ label: "Done", value: 8 }, { label: "In progress", value: 3 }, { label: "To do", value: 5 }],
  label: "Tasks by status",
  centerLabel: "Tasks",
});

Icons

Motion

Entrance animations play once on load; --delay staggers them. data-reveal waits until the element scrolls into view, and data-reveal-group on a parent staggers its children. data-count-to counts up to the number; write the real number in the HTML too, so it is right without JavaScript. data-marquee runs an endless strip and adds a pause button under it. All of it is skipped for people who turned on reduced motion.
