From zero to a running page in three steps

Everything runs from disk, so a double-click is enough to start.

  1. 1

    Copy the starter

    Copy starter/ to a new folder next to arsenal/, for example project/.

  2. 2

    Pick a look

    Add data-preset="forest" (or indigo, editorial, candy) to <html>, or set your own brand color.

  3. 3

    Paste and adapt

    Take sections from the page builder and components from the catalog, then change the text.

Two folders you copy into any project

The CSS is split into cascade layers, so your own styles always win. The JavaScript files are plain scripts that also work when the page opens from disk.

Read the wiki

css/

  • tokens.css colors, spacing, type, four presets
  • layout.css stack, cluster, sidebar, grids
  • components.css buttons to steppers
  • effects.css glass, glow, motion
  • utilities.css one-property classes

js/

  • dom.js $, on, h, html templates
  • store.js and router.js for apps
  • http.js and mock-api.js for data
  • ui.js modals, tabs, toasts, forms
  • charts.js bar, line and donut charts
  • icons.js 79 inline SVG icons
